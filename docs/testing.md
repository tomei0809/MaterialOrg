# テスト手順：Material Organization

自動テスト（コマンドで確認できるもの）と、画面での手動確認の手順をまとめる。
プッシュとプルリクエストのたびに、GitHub Actions（`.github/workflows/ci.yml`）が「2. 自動テスト」をすべて実行する。

## 1. 準備

- PostgreSQL を起動しておく。
- `backend` で `bundle install`、`frontend` で `npm install` を済ませておく。
- テスト用 DB の接続には、環境変数 `POSTGRES_PASSWORD`（ローカルの postgres ユーザーのパスワード）を使う。

## 2. 自動テスト

### 2.1 バックエンド（Rails）

```bash
cd backend
bin/rails db:test:prepare test      # モデル・コントローラーのテスト（Minitest）
bin/rubocop                         # コードスタイル（rubocop-rails-omakase）
bin/brakeman --no-pager             # セキュリティの静的解析
bin/bundler-audit                   # 既知の脆弱性がある gem の検出
```

| テストファイル | 確認していること |
|---|---|
| `test/models/material_test.rb` | 必須項目、種類の値、拡張子の許可リスト（大文字・拡張子なし）、ファイルサイズ上限、タグの再利用・整形（空白・重複・全角）・個数と長さの上限、ゴミ箱（まとめから外れる・更新日を変えない・元に戻す・期限切れだけを完全に削除・`PurgeTrashJob`） |
| `test/models/folder_test.rb` | 同じ親の中での名前の重複、循環の禁止、5階層の上限（サブフォルダごとの移動を含む）、末尾への追加、`arrange` の並び替えと取り消し、削除時に中身を親の末尾へ移すこと |
| `test/controllers/materials_controller_test.rb` | タグ・フォルダ（未分類を含む）での絞り込み、タグ付き登録、動画・コードの添付、非対応形式の拒否（422）、更新失敗時のタグの巻き戻し、フォルダへの移動、まとめへの出し入れ、お気に入り・開いた記録（`updated_at` を変えない）、タグ一覧、ゴミ箱（削除で一覧・フォルダの件数・タグから消える、一覧の `purge_at`、元に戻す、ゴミ箱の教材を一括操作の対象にしない、選んだもの・すべての完全削除、期限切れの削除） |
| `test/controllers/folders_controller_test.rb` | 一覧（空のフォルダ・並び順）、作成・更新・削除、名前の重複や不正な色の拒否、サブフォルダの移動、子孫への移動の拒否、`arrange` による入れ子・最上位への移動 |
| `test/controllers/bundles_controller_test.rb` | 作成と同時にまとめる（元のまとめが空なら削除）、入力不足の拒否、名前の変更、解除しても教材が残ること、並び替えと不一致の拒否 |

テストは1つの DB 接続で順番に実行する（`test/test_helper.rb` の `parallelize(threshold: 500)`）。並列にすると、外部キーのあるテストどうしが干渉するため。

### 2.2 フロントエンド（Next.js）

```bash
cd frontend
npm run lint        # ESLint（React Compiler のルールを含む）
npm run typecheck   # TypeScript の型チェック（tsc --noEmit）
npm run build       # 本番ビルド（ページの事前生成まで通ること）
```

## 3. 手動確認（画面）

`bin/rails server`（:3000）と `npm run dev -- -p 3001` を起動し、http://localhost:3001 を開いて確認する。
ライト・ダークの両方と、スマホ幅（ブラウザの開発者ツールで 390px 程度）でも主要な操作を確かめる。

### 3.1 登録・編集・削除

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | 「＋ 教材」から PDF を選び、タイトル・種類・タグを入れて保存 | 一覧の先頭に表示され、詳細パネルにファイル名・サイズ・プレビューが出る |
| 2 | 一覧へファイルを複数ドラッグ＆ドロップ | 登録の確認ダイアログに全件が並び、まとめて登録できる |
| 3 | `.exe` など許可されていないファイルを登録 | 「この形式のファイルはアップロードできません」と出て保存されない |
| 4 | タグを11個付けて保存 | 「タグは10個までです」と出る |
| 5 | 詳細パネルの「編集する」でタイトルを変えて保存 | 一覧と詳細に反映され、更新日が変わる |
| 6 | 詳細パネルの「ゴミ箱へ」（または選んで Delete キー） | 確認なしで一覧から消え、「ゴミ箱へ移動しました［元に戻す］」の通知が出る。まとめの最後の1件だったときは、まとめも消える |

### 3.2 フォルダ

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | サイドバーの「＋」でフォルダを作り、色を選ぶ | サイドバーとマップにその色で出る |
| 2 | フォルダ名をダブルクリック（または F2、右クリック →名前の変更）して変更 | その場で名前が変わる。同じ階層に同名があるとエラーになる |
| 3 | フォルダ sub をフォルダ main の上へドラッグ | sub が main の中へ移る。6階層目になる移動は拒否される |
| 4 | フォルダを別のフォルダの上下の端へドラッグ | 並び順が変わり、再読み込みしても保たれる |
| 5 | 中身のあるフォルダを削除 | 中のサブフォルダと教材が1つ上の階層（最上位なら未分類）へ移る |
| 6 | サイドバーでフォルダの ▶ を開く | 子フォルダの下に教材名が並ぶ。クリックで詳細、ダブルクリックでビューアが開く |

### 3.3 まとめ・並び替え

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | 教材の行を別の教材の行の上へドラッグ | 2件が「まとめ」になる |
| 2 | まとめを展開し、中の教材をドラッグで並べ替え | 順番が変わり、再読み込みしても保たれる |
| 3 | 教材を選んで右クリック →フォルダへ移動 | 選んだ全件が移る |

### 3.4 資料マップ・検索

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | 「すべての教材」でマップを見る | フォルダ（main）の中にサブフォルダ（sub）が入れ子で出る。孫以下は「📁＋n」の札になる |
| 2 | マップの sub の区画をクリック | そのフォルダへ移り、マップがそこを起点に描き直される。左端の「上の階層へ」で戻れる |
| 3 | 区画の種類アイコンをクリック | その種類で絞り込まれる |
| 4 | 教材をマップの区画へドラッグ | そのフォルダへ移動したと通知が出る |
| 5 | 検索欄に語を入れて Enter、次に検索欄をクリック | 結果が絞り込まれ、直近の検索が最大8件出る |
| 6 | 一覧の列数を 1・2・3 列に切り替え | 幅に応じて並ぶ列が変わる（1列あたり最低 420px） |

### 3.5 プレビュー・ビューア

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | PDF の行にマウスを乗せる | 約0.5秒後にプレビューが出て、ページがスライドショーで送られる |
| 2 | 動画・コードの行にマウスを乗せる | 動画は音なしで再生、コードは自動スクロールと構成の一覧 |
| 3 | 行をダブルクリック（または選んで Space） | 画面全体のビューアが開く。Esc で閉じる |
| 4 | PDF・画像で Ctrl＋ホイール、ドラッグ | カーソル位置を中心に拡大し、ドラッグで移動できる |
| 5 | コードで Ctrl+F | 一致の数が出て、Enter で次の一致へ移る |
| 6 | docx・pptx・xlsx・CSV・ZIP を開く | 見出し・スライドとノート・シートのタブ・表・ZIP の中身が表示される |
| 7 | 音声の波形・動画のシークバーで位置を移す | 指定した位置から再生される（Range リクエスト） |
| 8 | Shift+→ | 一覧の次の教材へ移る |

### 3.6 お気に入り・最近使った資料

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | 行の☆をクリック（または選んで F キー） | ★になり、サイドバーの「お気に入り」に入る。更新日は変わらない |
| 2 | 教材をビューアや詳細で開く | 「最近使った資料」の先頭に入る |
| 3 | 教材をサイドバーの「お気に入り」へドラッグ | お気に入りに入る |

### 3.7 ゴミ箱

| # | 操作 | 期待する結果 |
|---|---|---|
| 1 | 教材を選んで Delete キー → 通知の「元に戻す」 | 一覧から消え、「元に戻す」で同じフォルダに戻る。サイドバーの「ゴミ箱」の件数が増えて戻る |
| 2 | 教材をサイドバーの「ゴミ箱」へドラッグ | ゴミ箱へ移る |
| 3 | サイドバーの「ゴミ箱」を開く | 削除した日と「あと n 日で完全に削除」が出る。残り3日以内は赤字 |
| 4 | ゴミ箱で選んで「元に戻す」 | 元のフォルダに戻る（フォルダを消していれば、その親か未分類） |
| 5 | ゴミ箱で選んで「完全に削除…」→ 確認で OK | ゴミ箱から消え、添付ファイルも消える |
| 6 | 「ゴミ箱を空にする…」→ OK | 「ゴミ箱は空です」になり、件数が 0 になる |
| 7 | ゴミ箱の教材のタグ | タグ一覧の件数に数えられない |

## 4. 本番環境での確認

デプロイ後は [本番環境への移行手順](deployment.md) の「5. 公開後の確認」に沿って、`/up` の応答、アップロード、S3 への保存、ファイルの配信、動画の位置合わせ、ゴミ箱を確かめる。
