# システム構成設計：Material Organization

## 1. 目的

Material Organizationの構成要素、各技術の役割、およびデータの流れを定義する。

## 2. システム構成

```text
[利用者のブラウザ]
        |
        | 画面操作
        v
[React + TypeScript]
        |
        | HTTPリクエスト / JSON
        v
[Ruby on Rails API]
        |
        +----------------------+
        |                      |
        v                      v
[PostgreSQL]            [Active Storage]
資料情報・科目情報              |
                               v
                       [ファイル保存先]
                       開発時：ローカル
                       本番候補：Amazon S3
```

## 3. 各技術の役割

### 3.1 React + TypeScript

- 資料一覧、登録フォーム、詳細画面などを表示する。
- ユーザーの入力や検索条件を管理する。
- Rails APIにHTTPリクエストを送信する。
- APIから受け取ったJSONを画面に反映する。

### 3.2 Ruby on Rails

- HTTPリクエストを受け取る。
- リクエストの入力値を検証する。
- 資料や科目の登録・取得・更新・削除を行う。
- データベースとのやり取りを行う。
- ファイルの添付・取得を管理する。
- 認証・認可を行う。

### 3.3 PostgreSQL

- 科目情報を保存する。
- 資料のタイトルや説明などを保存する。
- 科目と資料の関連を管理する。
- 検索や並べ替えに必要なデータを提供する。

### 3.4 Active Storage

- 資料レコードとファイルを関連付ける。
- ファイルのアップロードと取得を管理する。
- 開発時のローカル保存と本番環境の外部ストレージを切り替えられるようにする。

### 3.5 Amazon S3

本番環境でファイルを外部保存する場合に利用する。初期開発では必須とせず、ローカル保存で動作確認する。

### 3.6 Git・GitHub

- ソースコードと変更履歴を管理する。
- 機能単位でブランチを分ける。
- 必要に応じてGitHub Actionsでテストを自動実行する。

## 4. 通信方式

- フロントエンドとバックエンドの通信方式はHTTPとする。
- 通常のデータ交換にはJSONを使用する。
- ファイルのアップロードではmultipart/form-dataを使用する。
- APIのパスには `/api` を付ける。
- 成功時と失敗時で適切なHTTPステータスコードを返す。

## 5. データ処理の流れ

### 5.1 資料一覧の取得

1. 利用者が資料一覧画面を開く。
2. ReactがRails APIへGETリクエストを送信する。
3. RailsがPostgreSQLから資料情報を取得する。
4. RailsがJSON形式でレスポンスを返す。
5. Reactが資料一覧を表示する。

### 5.2 資料の登録

1. 利用者が資料情報とファイルを入力する。
2. Reactがフォームデータを送信する。
3. Railsが入力値とファイルを検証する。
4. Railsが資料レコードとファイルの関連付けを保存する。
5. 成功時は登録した資料情報を返す。
6. Reactが一覧画面などを更新する。

## 6. セキュリティ方針

- 本番環境では認証・認可を実装する。
- Rails側ですべての重要な入力検証を行う。
- フロントエンドだけでアクセス制御を完結させない。
- データベース接続情報やストレージ認証情報を公開しない。
- ファイルへのアクセスは権限を確認した上で許可する。
- HTTPSを利用する。
- フロントエンドとバックエンドを別オリジンにする場合は、CORS、Cookie、CSRF対策を構成に応じて設定する。

## 7. デプロイ方針

開発時はローカル環境で実装・検証する。公開時はRails、React、PostgreSQLをホスティング環境へ配置し、ファイル保存先と環境変数を設定する。

デプロイ先は、対応するRails実行環境・PostgreSQL・ファイルストレージを利用できるサービスから選定する。
