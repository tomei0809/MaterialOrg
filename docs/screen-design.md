# 画面設計：Material Organization

画面は1ページ（`/`）で構成し、登録・詳細・編集・ビューア・ゴミ箱は、ページを離れずに重ねて表示する（ドロワー・ダイアログ）。
当初の設計にあった「科目管理」の画面は、フォルダで置き換えたため設けない。

## 1. 画面構成

```text
┌────────────┬──────────────────────────────────────────────┐
│ サイドバー   │ 見出し（現在地のパンくず・件数）   ＋フォルダ ＋教材 │
│            │ 検索欄（直近8件の履歴）                          │
│ ライブラリ   │ 資料マップ（フォルダ main → sub の2階層）          │
│  すべて     │ ツールバー（区切り・並び・列数・密度・マップ）       │
│  お気に入り  │ 種類のタブ                                     │
│  最近使った  │ 一覧（1〜3列・フォルダごとの区切り・まとめ）        │
│  最近追加   │                                              │
│  未分類     │                         ┌ 詳細パネル（右から）──┐ │
│  ゴミ箱     │                         │ プレビュー・情報・操作 │ │
│ フォルダの木 │                         └──────────────────┘ │
│ タグ        │                                              │
└────────────┴──────────────────────────────────────────────┘
```

| 部分 | 主な機能 |
|---|---|
| サイドバー | ライブラリの切り替え、フォルダの木（展開で教材名、ドラッグで並び替え・入れ子）、タグ、ゴミ箱。たたむとアイコン表示 |
| 検索欄 | タイトル・フォルダ名・タグ・説明の検索。`/` キーで移動 |
| 資料マップ | 面積＝件数。区画を押すとそのフォルダへ、種類のアイコンを押すとその種類で絞り込む。教材をドロップして移動 |
| 一覧 | 選択・まとめての移動・ゴミ箱へ・お気に入り。行をドラッグしてまとめる・並べ替える。右クリックで簡易編集 |
| 詳細パネル | プレビュー、ファイル名（クリックでビューア）、フォルダ・タグ・説明・日時、編集・ゴミ箱へ |

## 2. 重ねて表示する画面

| 画面 | 開き方 | 主な機能 |
|---|---|---|
| 教材の登録 | 「＋ 教材」・N キー・ファイルのドロップ | タイトル（必須）、種類（必須）、フォルダ、タグ、説明、ファイル。複数ファイルは確認ダイアログで一括登録 |
| 教材の編集 | 詳細パネルの「編集する」 | 登録と同じ項目。現在の値を初期値にする |
| ビューア | 行のダブルクリック・Space キー・詳細の「開く」 | 画面全体で表示。拡大・移動・ページ送り・検索、前後の教材へ移動、保存 |
| フォルダの作成・編集 | 「＋ フォルダ」・フォルダの右クリック | 名前・色・置き場所、削除（中身は親へ移す） |
| まとめ | 複数を選んで「まとめる」・行を重ねる | 名前、中の並び順 |
| ゴミ箱 | サイドバーの「ゴミ箱」 | 元に戻す・完全に削除・空にする。残り日数を表示 |
| 表示設定 | サイドバー下の「表示設定」 | テーマ（ライト・ダーク）・アクセントの色 |

## 3. ログイン・新規登録・パスワード

| 画面 | パス | 主な機能 |
|---|---|---|
| ログイン | `/`（ログインしていないとき） | メールアドレス・パスワード、パスワードの表示切り替え、「パスワードを忘れた方」 |
| 新規登録 | `/`（タブで切り替え） | メールアドレス・パスワード（8文字以上）・確認用。登録するとそのまま一覧へ |
| パスワードを忘れた方 | `/`（ログイン画面から） | メールアドレスを入れると、再設定のリンクを送る |
| 新しいパスワードの設定 | `/reset-password?token=…` | メールのリンクから開く。新しいパスワードを2回入力 |
| アカウント | 設定のダイアログ | メールアドレスの表示、パスワードの変更、ログアウト（サイドバーの下からもログアウトできる） |

- 使っている途中でログインが切れたら、ログイン画面に「有効期限が切れました」と出して戻る。
- ログアウトすると、この端末に残っている検索履歴を消す。

## 4. 共通仕様

- PC とスマートフォンの画面幅に対応する（スマホではサイドバーを開閉式、マップを行の形にする）。
- 通信中は読み込み状態を、通信失敗時はエラーメッセージを表示する。
- 検索結果が0件の場合は、該当資料がないことを表示する。
- 削除はゴミ箱へ移し、通知の「元に戻す」で取り消せるようにする（確認ダイアログは出さない）。完全に削除するときだけ確認する。
- 色はフォルダだけに使い、種類は墨一色のアイコンの形で表す。
- ボタン・フォームには分かりやすいラベルを付け、キーボードでも操作できるようにする。
- バックエンドの入力検証エラーを画面に表示する。

## 5. キー操作

| キー | 動作 |
|---|---|
| `/` | 検索欄へ |
| `N` | 教材の登録 |
| `Space` | 選択中の教材をビューアで開く |
| `F` | お気に入りに入れる／外す |
| `F2` | 名前の変更 |
| `Delete` | ゴミ箱へ |
| `Backspace` | 1つ上のフォルダへ |
| `Esc` | ビューア・ダイアログを閉じる |
