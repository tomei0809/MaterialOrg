# 第3回 固有値と固有ベクトル（自分用まとめ）

## ポイント
- **Av = λv**（v ≠ 0）を満たす λ が固有値、v が固有ベクトル
- 求め方：特性方程式 `det(A − λI) = 0` を解く
- 固有値が異なれば、固有ベクトルは一次独立

## 例
| 行列 | 特性方程式 | 固有値 |
| --- | --- | --- |
| (4 −2 ; 1 1) | λ² − 5λ + 6 = 0 | 2, 3 |
| (2 1 ; 1 2) | λ² − 4λ + 3 = 0 | 1, 3 |
